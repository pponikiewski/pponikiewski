## Projekty

### ⏱️ [Tracker](https://github.com/pponikiewski/tracker)
Desktopowy time tracker dla zespołów (multi-tenant) z synchronizacją do chmury. Drzewo projektów `project → stage → substage → task`, logowanie czasu, dashboard z wykresami, workspace'y z linkami zaproszeń i rolami. Offline-first: lokalna baza SQLite, kolejka zmian (outbox) i scalanie LWW z Supabase, realtime i presence. Eksport CSV/Markdown, backup JSON, auto-updater przez GitHub Releases.  
`Tauri 2` `Rust` `React 19` `TypeScript` `SQLite` `Supabase` `Zustand` `Recharts`  
📦 [Pobierz najnowszą wersję](https://github.com/pponikiewski/tracker/releases/latest)

### 🩺 [NetDoctor](https://github.com/pponikiewski/netdoctor)
Diagnostyka sieci i optymalizacja opóźnień dla Windows. Odpowiada na pytanie: *gdzie dokładnie zrywa się połączenie?* Równolegle pinguje router i kilka adresów w internecie, a z układu błędów wskazuje winnego: kartę Wi-Fi, router, dostawcę albo DNS. Jeden plik `.exe` (~5 MB), bez instalatora i zależności.  
`Rust` `egui` `Win32 API` `SQLite`  
📦 [Pobierz najnowszą wersję](https://github.com/pponikiewski/netdoctor/releases/latest)

### 🌹 [Róża Różańcowa](https://github.com/pponikiewski/roza-rozancowa)
Aplikacja webowa do zarządzania grupami Żywego Różańca: automatyczna rotacja tajemnic, zarządzanie członkami, komunikacja we wspólnocie.  
`React 19` `TypeScript` `Vite` `Supabase` `TanStack Query` `Zod` `Playwright`  
🔗 [Demo](https://roza-pd.vercel.app)

### 🗂️ [Portfolio](https://github.com/pponikiewski/Portfolio)
Dwujęzyczna (PL/EN) strona portfolio. Statyczne Astro, zero JavaScriptu po stronie klienta, testy na zbudowanym wyniku, Lighthouse 99–100.  
`Astro` `TypeScript` `CSS` `GitHub Actions`  
🔗 [pponikiewski.dev](https://pponikiewski.dev)

### 💰 [Budgie](https://github.com/pponikiewski/budget)
Desktopowa aplikacja do domowego budżetu. Przychody i wydatki z kategoriami, bilans na żywo, filtr po miesiącu, zestawienie wydatków per kategoria. Dane lokalnie w SQLite, działa offline, bez konta.  
`Tauri 2` `Rust` `React 19` `TypeScript` `SQLite` `Drizzle ORM` `Tailwind v4`
